# AI Fashion Video Generator (Stable Video Diffusion)

Automated AI Video Diffusion Pipeline that transforms flat dress & fashion photos into realistic animated videos via GitHub Actions.

---

## Features

- **True AI Video Diffusion**: Uses Stable Video Diffusion (SVD) on cloud GPUs.
- **Zero Local Load**: All AI inference runs in the cloud via GitHub Actions.
- **1-Click Generation**: Upload any dress photo to `inputs/dress.jpg` and get the video artifact.

---

## Usage

1. Go to **Actions** in `https://github.com/nazihyazan/gent-loop-lab`
2. Select **AI Video Catwalk Generator (Stable Video Diffusion)**
3. Click **Run workflow**
4. Once completed (~1 min), download the MP4 video from **Artifacts** (`ai-dress-catwalk-video`).
